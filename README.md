# 🏗️ Sistema de Gestão em Engenharia de Serviços

> Aplicação desenvolvida para apoiar o gerenciamento de serviços de engenharia, permitindo controlar demandas, acompanhar atividades, organizar informações e otimizar a gestão operacional por meio de uma plataforma centralizada.

Este projeto integra meu portfólio de desenvolvimento de software e demonstra conhecimentos em desenvolvimento web, banco de dados, modelagem de sistemas e criação de soluções voltadas para processos corporativos.

---

# 📋 Sobre o Projeto

O **Sistema de Gestão em Engenharia de Serviços** foi desenvolvido com o objetivo de facilitar o gerenciamento das atividades executadas por equipes de engenharia, proporcionando maior organização, rastreabilidade e controle das operações.

A proposta da aplicação é substituir controles manuais e planilhas por um sistema integrado que permita acompanhar solicitações, registrar informações relevantes e apoiar a tomada de decisão através de uma interface intuitiva.

---

# ⚙️ Como Executar

## Clone o repositório

```bash
git clone https://github.com/Daniel010203/Projeto-para-Gest-o-em-Engenharia-de-serv-os.git
```

## Acesse a pasta

```bash
cd Projeto-para-Gest-o-em-Engenharia-de-serv-os
```

## Configure o ambiente

Caso utilize o XAMPP:

* Inicie o Apache
* Inicie o MySQL
* Copie o projeto para a pasta **htdocs**

## Banco de Dados

Crie um banco MySQL e importe o arquivo `.sql` disponibilizado no projeto (quando disponível).

## Execute

```text
http://localhost/Projeto-para-Gest-o-em-Engenharia-de-serv-os
```
